# Autonomous Quote Agent Intelligence Platform

## Overview

The Autonomous Quote Agent Intelligence Platform is a multi-agent AI system that automates the auto insurance quote evaluation process.

The platform processes insurance quotes through a sequence of intelligent agents that:

- Analyze customer risk
- Predict policy conversion probability
- Recommend premium adjustments
- Route business decisions automatically
- Generate structured decision analysis
- Provide AI-powered explanations using a local LLM

This project was developed as a hackathon solution to demonstrate how Agentic AI can automate insurance workflows while maintaining explainability and human oversight.

---

## Problem Statement

Insurance companies generate thousands of quotes every day, but only a fraction convert into policies.

Manual review is often required to determine:

- Why a customer may or may not convert
- Whether the quoted premium is appropriate
- Whether a quote requires agent intervention
- Whether the case should be escalated to underwriting

This manual process increases operational cost and delays decision-making.

---

## Solution

The Autonomous Quote Agent introduces a multi-agent pipeline that automates quote evaluation from end to end.

The system consists of four specialized AI agents:

### 1. Risk Profiler Agent
Analyzes customer and vehicle information to classify risk as:

- LOW
- MEDIUM
- HIGH

### 2. Conversion Predictor Agent
Uses a trained Machine Learning model to predict:

- Conversion outcome
- Conversion probability

### 3. Premium Advisor Agent
Recommends a premium adjustment based on:

- Risk level
- Conversion probability
- Current quoted premium

### 4. Decision Router Agent
Determines the final business action:

- AUTO APPROVE
- AGENT FOLLOW-UP
- ESCALATE TO UNDERWRITER

### 5. Decision Analysis Layer
Provides:

- Confidence scoring
- Risk factor identification
- Business reasoning
- Premium adjustment explanation
- Recommended actions

### 6. AI Explanation Layer
Uses Ollama with Llama 3.2 to generate natural-language explanations for business users.

---

## True Agent Chaining

The system implements sequential agent chaining where the output of one agent becomes the input for the next.

```text
Risk Level
      ↓
Conversion Probability
      ↓
Premium Recommendation
      ↓
Final Decision
      ↓
Decision Analysis
      ↓
AI Explanation
```

This ensures that each decision incorporates outputs generated by earlier agents.

---

## Human-in-the-Loop Design

Although the platform automates decision-making, it preserves human oversight.

### AGENT FOLLOW-UP
Cases requiring customer interaction are routed to an insurance agent.

### ESCALATE TO UNDERWRITER
Complex or high-risk cases are escalated for manual underwriting review.

This balances automation with responsible decision-making.

# How to Run the Project

## 1. Clone Repository

```bash
git clone https://github.com/J-sravani15/autonomous-quote-agent.git

cd autonomous-quote-agent
```

---

## 2. Install Backend Dependencies

```bash
cd backend

pip install -r requirements.txt
```

---

## 3. Start Ollama

Verify that Ollama is installed and running:

```bash
ollama list
```

Required model:

```bash
llama3.2
```

If needed:

```bash
ollama run llama3.2
```

---

## 4. Run FastAPI Backend

From the backend directory:

```bash
python -m uvicorn app.main:app --reload
```

Backend URL:

```text
http://127.0.0.1:8000
```

Swagger Documentation:

```text
http://127.0.0.1:8000/docs
```

---

## 5. Run Frontend

Open:

```text
frontend/index.html
```

or launch using VS Code Live Server.
